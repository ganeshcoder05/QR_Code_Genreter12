# 🔳 QR Code Generator

A simple and interactive QR Code Generator built using HTML, CSS, and JavaScript.

---

## 📌 Features

- Generate QR code instantly ⚡
- Supports text and URL input 🔗
- Real-time QR preview 👀
- Download QR code option 📥
- Clean and responsive UI 📱

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

---

## 📂 Project Structure

```
├── index.html
├── style.css
├── script.js
```

---

## ⚙️ How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. Enter text or URL
4. Generate your QR code
